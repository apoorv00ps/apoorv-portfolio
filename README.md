# Apoorv Raj Shringi Portfolio

A modern personal portfolio website built with Next.js, HTML, CSS, and JavaScript.

## Features
- Futuristic indie game studio aesthetic
- Hero, About, Skills, Education, Experience, Projects, Achievements, Certifications, Languages, Vision, and Contact sections
- Responsive mobile navigation and expandable project gallery
- Modular component structure for easy editing
- Placeholder image assets in `public/`

## Setup
1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the development server:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```

## Notes
- Replace `public/profile-placeholder.svg` with your own portrait image
- Update content in `data/portfolioData.js` for custom portfolio text
